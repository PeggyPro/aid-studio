# 画布审核后台接入

页面组件 `aid/canvasAudit/index` 由现有动态菜单加载，放置在“审核管理”目录；流程审核继续使用 `aid/audit/index`，无需静态路由或占位页。目录、页面及按钮菜单由配套服务端唯一未发布 SQL 维护，后台不自建菜单数据。

旧流程审核书签 `/comic/comicaudit` 仅在已登录、具有 `aid:audit:list` 且服务端动态路由确实授予流程审核页面时，跳转到当前动态地址并保留查询参数与片段。目标随菜单配置变化，不开放匿名入口或额外接口权限；当前地址可直接访问。此兼容无需 SQL。

权限分离：`aid:canvasAudit:list` 读取列表，`aid:canvasAudit:query` 查询详情与媒体，`aid:canvasAudit:review` 通过/驳回，`aid:canvasAudit:offline` 下架。页面失去查询权限后关闭详情并清除正文；失去列表权限后停止读取。服务端仍需逐请求校验权限。

API 统一使用 `/aid/audit/canvas`：POST `list`、`detail`、`review`、`offline`；GET `media`。列表 `data={items,total}`；分页 1 起，最大每页 100。ID 全程原样传递。审核 `action=APPROVE|REJECT`，下架独立 `action=OFFLINE`；`expectedVersion=detail.stateVersion`，驳回/下架理由必填且最多 1000 字。版本冲突或结果未知时重新查询固定版本，不自动重放写请求。

详情须返回权威 `isPublic` 及 `visibility`，与历史 `reviewStatus` 分开；已通过的固定版本可以处于未公开状态。下架入口只在 `isPublic=true`、`publishedVersion.publicationId` 等于当前 `publicationId` 且有独立下架权限时展示；空摘要、其他固定版本或状态缺失均不提供下架入口。下架后以服务端公开状态确认结果，不把历史审核状态误作当前可见性。

`detail.canvas` 必须包含 `objects/resources/currentResults/sceneDocument/videoResourceId/coverResourceId`。正文对象沿用固定 `objectType/content`；场景按完整资源引用协议提供。资源 `bundle={format,rootPath,files:[{path,resourceId,resourceUrl}],references:[{ownerPath,uri,path}]}`，模型与场景包包含原文件及全部依赖。所有媒体先在同源认证网关取得 Blob，禁止给未知外链发送登录令牌，禁止直接访问源存储。模型 URLModifier 只能映射到冻结文件。保留原有资产内部渲染规则（包括 source 区分的比例及中心/落地解释），不改变对象世界变换、场景坐标或固定机位，不使用默认模型替代缺失资源。

页面逐项检查视频、封面、全部节点（包含折叠/视野外内容）、分组、连线、文本、参数、当前结果、完整场景、模型/场景包、对象变换、姿态、相机与时间线。骨骼姿态只在固定模型存在相应映射时应用；未知模型或姿态映射失败可见。模型包 GLB/GLTF、FBX、OBJ/MTL 按封闭依赖加载，压缩扩展未提供解码器会失败关闭。时间线按固定 currentTime 演算对象、姿态及相机关键帧、动作片段/导入动作、blendIn 与前段保持、路径移动、相对/轨迹/固定跟随及 lookAt，Quaternion 插值保持原旋转语义。未加载、无法解码或未知不可忠实还原的资源/能力禁止通过。检查不会更改固定场景文档。

完整场景默认使用“原始视角”，保留保存的机位和照明。无光或画面外内容可切换“辅助审查”：仅在本地临时补光，以完整场景或所选对象的世界边界设置审查相机，可旋转、平移和缩放观察；不改变任何物体的世界变换、姿态、材质、时间线或保存的相机/灯光，不发送保存请求，也不改变当前路由的 query/hash。切回原始视角即可恢复作品原貌。辅助视角不能替代原始视角的构图核对，资源解析/骨骼检查失败仍禁止通过。无需 SQL。

`sourceComparison/publishedComparison.available=false` 显示不可比较原因；差异及无来源记录均不构成原创、侵权或再次发布授权认定。复制来源及原发布版本可查询对应固定详情与视频/封面/完整正文，审核人员必须自行检查。驳回保留旧发布版本，通过切换整份固定版本，下架由服务端取消待审扩权。

本地受控夹具只验证交互和请求合并；真实接口、权限、历史版本授权、资源包与发布状态仍须在已部署对应提交的隔离测试环境验收，不能用夹具代替服务端证据。

## 真实接口验收入口

登录已部署此提交的隔离后台，展开“审核管理”→“画布审核”。如果菜单没有出现，先核对配套服务端菜单 SQL、当前账号的列表/详情权限与动态菜单响应，不能用静态假菜单代替。流程审核继续从同目录的原路由进入。

使用测试账号固定作品依次覆盖：待审查询/分页/关键词、全部固定内容及视野外节点、来源/原发布对比、显式模型与完整包依赖、通过/驳回/下架及理由、复制权限变化和撤销后的历史版本。分别使用仅列表、列表+查询、审核、下架账号核对操作边界；管理员不可改正文。检查同一动作快速重复触发、重新查询与资源失败后的恢复，409 后核对新 stateVersion 且写请求不自动重放。

浏览器 Network 过滤 `/aid/audit/canvas/`，记录请求体、响应状态与数量：同请求键进行中只有一次读取；`force` 刷新仍合并在途读取；单次确认只有一次对应 review/offline。资源请求携带登录认证，源存储/未登记外链请求数必须为 0；检查 Blob 视频、封面、纹理、模型及场景包实际显示，损坏/断网不能通过。截图需逐张打开核对桌面、375px、错误状态及真实 3D 摆放。记录后台实际部署提交、配套服务端提交与每个用例的权威状态；夹具断言和接口 200 不能代替这些证据。
