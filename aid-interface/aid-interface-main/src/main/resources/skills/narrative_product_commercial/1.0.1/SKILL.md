# 剧情化产品广告

根据产品图片与信息创建有处境、冲突、情绪连接和产品记忆点的短广告。只有产品图或一个已知使用动作也可以启动，不强求完整 brief。每条只选一个有依据的主卖点或情绪价值，辅助卖点最多两个，也可以一个都没有；不能为了凑数新增产品能力。

适合短广告，不用于长剧本、多集连载、复杂互动、直播切片、纯口播或图文海报。创意提案和后续剧本都遵循下方产品边界；进入剧本、控制原画或视频执行前按需读取 [广告节拍与质量检查](references/commercial_beats.md)。

## 产品事实与创作边界

先确认用户允许表达的产品信息、已知使用动作和明确禁止增加的能力。用户明确要求“不新增功能卖点”“只使用这些动作”时，以这个范围约束全部母题、推荐方案、动作、字幕和后续提示词，不能用“创作假设”“建议核实”或片尾免责声明绕过。有更具体的用户限制时，通用的创作自由和辅助卖点数量不扩大该限制。

产品图片只能支持确实可见的外观与文字，不能由外形推断单手操作、防漏、保温时长、便携、快速、省力或其他性能。用户提供的产品资料与可信核验资料可作为对应主张的依据，表述强度不能超过资料；包装宣传也不能被说成已经独立验证。用户明确给出的普通动作，只支持该动作本身，不自动包含其速度、方便程度、持续时间或额外操作方式。

人物、场景、服装、光线、目标人群和调性可以在不违背 brief 的前提下标为待确认的创作设定。这类设定与产品功能主张分开：一个虚构角色或雨天场景，不会使未知功能获得依据；不能把被禁止的功能藏进剧情机制、动作细节、前后时间跨度或情绪结果中。情绪上的片刻安慰不等于提神、健康或恢复疲劳的产品功效。

没有足够产品证据时，仍围绕已知动作提出至少三个不同的情绪或叙事母题，例如陪伴、片刻从容和日常仪式；差异来自人物关系、微冲突和画面回收，不来自三种新功能。若唯一已知动作是打开容器、饮用一口温热饮品、继续行程，可以改写这次片刻的情绪处境，不能自行变成单手开盖、全天保温或长时间维持温度的证明。

确实影响方案的未知能力，放在简短的“待确认信息”中，并说明尚未用于推荐方案。确认前不把它作为辅助卖点、必要使用动作或可直接制作的备选剧本。不能一边标未知，一边用该功能推动推荐创意。

用户明确授权设计虚构产品或探索尚不存在的能力时，可以在该授权范围内提出清楚标注的概念方案，区分“拟议产品设计”与“真实产品事实”；仍保留用户的具体禁用项，不能把概念性能说成已实现。已有可信依据或用户明确确认的能力可正常创作，不因本规则一律删除功能卖点。若授权与具体限制冲突，先围绕确定允许的部分提案，再提出一项必要澄清。

## 创意链路

把有依据的产品价值或已知动作依次转换为用户处境、可见微冲突、产品介入、情绪或状态变化和结尾回收。冲突可以是喧闹与安静、匆忙与从容、孤单与陪伴。变化必须能由已知动作和剧情成立，不能依赖未知产品功效。产品自然出现、被允许的方式使用，并在结尾形成记忆，不让角色直视镜头背参数。

## 工作顺序

1. 读产品外形、包装、可见文字及用户资料。把有依据的信息、明确限制、可用动作、一般创作设定和待确认能力分开。为每项拟用卖点和产品动作找到对应来源；找不到依据且没有明确概念设计授权的，先移到待确认问题。
2. 选择一个有依据、适合画面表达的卖点；没有功能资料时使用已知动作带来的情绪价值。辅助卖点不是必填项，不能为了“最多两个”而补出两个。
3. 提出至少三个不同创意母题，分别说明剧情机制、情绪变化、产品角色、记忆画面、时长和风险，推荐一个。用一句自然语言说明各自依赖的已知信息或动作；纯人物、场景与调性设定单独注明，不把产品能力混在其中。
4. 建立时长结构：默认推荐三十秒，十五秒一段，三十秒两段，四十五秒三段，六十秒四段；前三秒有钩子。超过六十秒时说明更接近品牌短片，再确认结构与预算。目标人群与调性未知时可提出两到三个创作候选，但不借人群或情境推断产品性能。用户只要求母题时，交付到这一阶段并等待后续决定，不擅自推进媒体生成。
5. 在用户确认的范围内写具体视觉系统和剧本。剧情保持日常微冲突，少台词，多动作，结尾回扣开场。逐个检查开盖、携带、饮用、操作等动作是否只是已知动作，还是暗含方便、省时、防漏或其他新主张。
6. 分别建立无背景角色原画、无人场景原画、产品控制图和成片关键帧。用户产品图是产品身份最高依据，不改颜色、结构或标识；未经授权的功能设计不能通过多画按钮、改变开合方式或增加结构偷偷进入画面。
7. 每段内部按起、承、转、落写时间轴，显式引用产品、角色、场景和关键帧。视频可生已确认台词与受控字幕，不生背景音乐。每段仍只使用确认过的产品边界，不在扩写时补出新能力。
8. 所有段合成后统一生成覆盖全片的音乐、剪辑、字幕和品牌收束，并执行产品、一致性和真实感检查。默认音乐温暖明亮、积极、轻盈，以大调为建议，不给每个十五秒段各做一条音乐。

返回前自检：每项卖点和关键产品动作能否追溯到用户明确给定、已核验资料或明确的概念设计授权？画面跨度是否偷偷声称持续性能？动作是否暗示单手、省力、快速或防漏？人物的情绪改善是否被写成产品疗效？“假设”标签是否掩盖了一个已被用户禁止的能力？有问题时替换母题或动作本身，不只加免责声明。给用户保留简短清楚的依据与待确认信息，不堆内部审计表格。

平台没有对应图像、视频、音乐或合成能力时，在用户授权阶段保存相应节点、创作内容与提示词，明确尚未生成或合成。阶段推进和付费执行继续遵循用户决定与既有审批；首个真实生成失败暂停后续调用并保留已完成内容，不自动换付费模型或反复重试。
