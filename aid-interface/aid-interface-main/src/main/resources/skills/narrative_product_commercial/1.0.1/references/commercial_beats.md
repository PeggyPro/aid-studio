# 广告节拍与质量检查

## 产品边界先于卖点与节拍

主文件中的用户限制与证据规则适用于全部创意母题、推荐、剧本、分镜、动作、字幕和生成提示词。明确禁止增加的能力不能因“只是备选”“先标假设”而进入可制作的方案。辅助卖点最多两个，零个也完整；母题数量不等于功能数量。

开始前分别确认：
- 已知事实与动作：用户明确提供的信息、可信资料支持的能力，以及用户允许展示的普通使用动作。图片只证明真正可见的外观与文字，不单凭外形推断材质或性能。
- 创作设定：人物关系、生活处境、光线、服装、情绪与调性，在 brief 允许的范围内可提出并待用户确认。
- 未知能力：操作便利、使用速度、持续时长、防护、耐用、功效或其他未获依据的产品主张。它们只进入待确认问题，确认前不进入推荐方案或必要剧情动作。
- 概念设计授权：用户明确要求虚构产品能力时，按授权做条件性的产品概念，标明拟议设计；不能扩大到用户明确禁止的部分，也不能当作真实产品性能宣传。

每个卖点及产品动作都要有对应来源。用户说“打开杯子”，不等于“单手拧开”“一秒开启”或“省力开盖”；用户说“一口温热的茶”，不等于“从清晨到傍晚始终温热”。没有时长或操作资料时，不以首尾重复使用、天气变化、长途行程或连续工作隐含这些能力。不要用人物状态暗示未经确认的提神、恢复疲劳或健康功效。

来源说明保持简短，例如“依据：用户给出的温热饮用动作；雨天与人物关系为待确认的剧情设定”。不要把产品功能与人物设定合在一栏统一标成假设。待确认问题注明“尚未用于下列方案”；如果它已成为剧情成立的条件，应先改方案，不能只保留风险提示。

## 从已知动作到不同母题

从画面感、情绪关联、微冲突、记忆点和可信度选择主卖点或情绪价值。只有当相应能力有依据时，才可把隔绝噪声转为专注、续航转为长时陪伴、轻量转为动作从容；这些不是对任何产品都适用的默认卖点。

没有新功能证据，仍围绕同一个已知动作提出至少三个不同母题：可从人物关系、停顿与继续的节奏、日常仪式、反差或画面回收形成差异。比如同一次温热饮用，可以分别承载“独处时被照顾”“忙碌中的片刻停顿”“出发前熟悉的仪式”；这三种情绪表达本身不要求增加开盖、保温或防漏能力，也不承诺生理功效。用户不接受这些人物或情境设定时，再按其限制调整。

每个母题写标题、概念、剧情机制、情绪变化、产品角色、观众如何理解价值、记忆画面、时长和风险，然后推荐一个。风险不能成为保留违规功能的理由。推荐必须完全在当前证据与授权范围内成立；未知功能不作为可直接拍摄的附加选项。

默认有角色，角色有具体生活状态与轻微不完美，不使用塑料皮肤和空泛模特表情。产品露出完成可辨身份、允许的使用动作、剧情变化和片尾回收。产品带来的情绪意义与真实性能分开，不堆参数、对镜夸产品或让每镜都变成电商主图。

## 剧本与原画

剧本包含动作与场景描写，十五秒建议一百五十到二百五十字、三十秒三百到五百字、四十五秒五百到七百五十字、六十秒七百到一千字，上限一千字；这不是要求角色把全部文字说出来。对白少且自然，旁白说感受，台词字数符合真实语速。

按钩子、微冲突、产品介入、状态变化、结尾回扣推进。十五秒广告在前五秒建立产品身份，三十秒广告可在八到十二秒建立；之后使用允许的明确动作，结尾回收产品与开头关系。起点、终点、镜头时间跨度和旁白一起检查，不能靠跨时段剪辑暗示未经确认的持续性能。

先做控制原画，再合成关键帧，最后写视频。角色原画单人、无复杂背景、不拿产品、光线清楚；场景原画纯环境无角色；产品图以用户原图为最高依据，外观、颜色、结构、Logo 和按钮不能重设计。用户明确授权产品概念设计时，将拟议外观与既有实物区分；不擅自改用户要求保持的产品身份。关键帧组合角色、场景、产品、情绪与产品位置。镜头的色彩、光源、场景、服装和产品细节先形成一致性说明。

## 十五秒生成段

每段是一条视频任务，段内按零到三秒、三到七秒、七到十一秒、十一到十五秒组织节奏，不把四个节拍拆成四条生成。逐段写广告功能、剧情推进、动作、产品露出、景别、运镜、光线、情绪、剪辑点与前后衔接。相邻段用动作、视线、光线、颜色、产品特写或空间方向接续。

提示词引用产品、角色、场景和关键帧，再写主体、空间、允许的动作、情绪、产品位置、镜头、光线、色彩和按秒时间轴，最后规定结尾停留。禁止产品变形、改色、乱写标识和增加未经授权的按钮或操作方式。避免塑料皮肤、过度磨皮、样板间、无因霓虹与体积光、畸形手、漂浮道具和电商摆拍。

已确认台词注明说话人、时间点、语气与停顿，口型、台词和底部字幕一致；不自由添加台词，不出现随机文字。当前模型不能可靠生成受控文字时将字幕移到真实后期工具，不凭空声称烧录成功。视频不生成背景音乐，环境声克制。字幕与旁白也不能补上画面没有依据的产品承诺。

## 声音、返修与交付自检

先完成全部视频与拼接，再制作统一音乐。建议温暖、明亮、希望感与轻盈节奏，排除无依据的悲伤、恐怖、压抑、史诗煽情和廉价电子效果。整理旁白文案、情绪曲线、产品声音、环境声、拼接顺序、剪辑点、转场、字幕与品牌收束。

| 问题 | 回到的环节 |
|---|---|
| 开场没有吸引力 | 剧本开头与段内节拍 |
| 产品不突出 | 允许的露出动作与产品引用 |
| 人物或场景有明显生成感 | 控制原画、关键帧与负面约束 |
| 镜头太碎 | 十五秒内的节拍和切点 |
| 台词或字幕不一致 | 分镜台词、语速、口型与文字方式 |
| 视频段误生音乐 | 视频声音约束 |
| 全片音乐不统一 | 合成后统一音乐流程 |
| 卖点缺少来源、动作暗示未知便利或时长 | 产品事实边界，替换主张与剧情机制 |
| 假设标签掩盖用户禁止的能力 | 用户限制与母题本身，不能只补免责声明 |
| 卖点看不懂 | 有依据的主卖点筛选及处境转译 |
| 片尾没有记忆点 | 母题与开头回扣 |

交付前核对每个卖点、产品动作、时间跨度和结果表述的依据；确认零辅助卖点也可成立、三个母题没有借三个新功能区分、已确认能力没有被一概删掉、明确的虚构产品设计授权仍可合理使用。用户只要求创意母题时不擅自推进后续执行。必要待确认信息保留在方案外。

修正先定位原因，仅重做受影响产物，不因一项失败重跑整条链路。重新生成、换模型或增加费用由用户决定；已受理任务先核实原状态，不重复提交。
