# 单镜头沉浸叙事方法

## 单镜头约束

先建立可连续穿行的空间路线、时间长度、摄影机高度、人物进入退出和不可见转场点。所谓单镜头必须在空间和动作上可连接；如果需要明显跳时或换地点，应设计遮挡转场并如实标注，而不是文字声称“一镜到底”。

## 观众位置

确定观众是旁观者、角色视点还是可做选择的参与者。镜头距离、视线和信息获得方式要与身份一致。高潮来自观众在连续空间中积累的信息和风险，不靠突然切入未知地点。

## 动作与连续性

把路线分为若干连续段，每段记录进入位置、人物目标、可见行动、障碍、摄影机运动、声音线索和退出状态。道具、伤情、光线和人物距离跨段保持，任何状态变化都有可见触发。

## 分支设计

选择点嵌入自然停顿或注意力转移，不破坏镜头连续。每个选择改变路线、信息、关系或资源，并写入状态变量。分支重新汇合时说明哪些状态必须兼容；不允许丢弃玩家已造成的后果。

## 结局与测试

结局由累计状态和关键选择共同决定，提前布置可见信号。测试覆盖每个选择、变量边界、断点恢复、汇合冲突和无效状态。普通视频只能预览某一条路径，不等于已完成互动作品。

## 依赖状态

输出空间路线、连续段表、选择图、变量字典、结局条件和测试用例。缺少互动状态引擎、变量持久化、分支播放器或发布器时标 `DEPENDENCY_BLOCKED`；不得生成伪造运行记录或自动升级收费模型。
