# 漫画女性主角设计方法

## 叙事起点

从角色在故事中的功能、欲望、矛盾和行动方式出发，确定视觉关键词。外形设计应帮助读者快速识别角色，也要为不同状态留出变化空间。避免用单一“漂亮”模板替代人物性格。

## 识别系统

建立轮廓、发型大形、脸部识别点、主辅配色、服装结构、标志道具和动作习惯。每项说明叙事原因与不可变程度。高频细节集中在脸、手和关键道具，远景仍靠轮廓与配色辨识。

## 设计板

建议包含主视图、侧背轮廓、服装拆解、表情范围、手持道具和两到三个剧情状态。多视图保持同一比例与造型；表情变化要体现眉眼、嘴型、头部角度和姿态联动。设计板不等于视频分屏。

## 版本与变化

基础版本保存稳定身份。换装、受伤、伪装、时间跳跃等建立派生版本，并记录继承与变化。用户只要求改一个变量时，不同时改变脸型、发型和体型。

## 视觉提示

提示按身份、轮廓、服装材质、配色、表情动作、构图和媒介语言组织。不要填入特定供应商的 seed、权重或私有参数。需要文字排版或后期合成时单列交付，不能把无字图生成器当作已完成排版工具。

## 自检

检查近景与远景辨识、正侧背一致、服装可穿性、道具归属、表情范围、配色层级和剧情状态。缺少身份锁、局部编辑或排版工具时，明确限制并交付设计稿，不声称已完成技术锁定。
