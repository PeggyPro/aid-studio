# 漫画男性主角设计方法

## 人物到形态

从角色目标、社会身份、能力边界、日常习惯和核心矛盾提取视觉语言。体态表达人物如何占据空间：开放或收缩、稳定或游移、习惯先看还是先动。不要把“主角感”简化为夸张肩宽、统一高个或冷脸。

## 辨识层级

远景靠轮廓、比例和配色；中景靠服装结构、姿态和道具；近景靠脸部识别点、发型、表情和细小磨损。选择两到四个稳定记忆点，避免同时堆满无关装饰。

## 角色表

主视图确立整体语言，多视图解释发型、服装和道具结构，表情组覆盖平静、警觉、压抑、愤怒、脆弱和轻松等对剧情有用的状态。表情区别通过眼周、下颌、嘴部、头颈和手势联动，不用滤镜替代表演。

## 服装与细节

服装要符合职业、年代、行动和气候。材质、开合、口袋、鞋与道具位置应在多视图中一致。战损或时间变化作为状态版本，记录从哪个基础造型派生。

## 一致性与工具边界

为每个资产绑定角色和造型 revision，生成前由代码核验参考数量与模型能力。未绑定身份保持、局部编辑或后期排版能力时，只交付设计规格和可编辑提示，不声称已锁定脸或完成合成。

## 自检

检查角色与故事功能是否一致、远中近景是否可识别、多视图结构是否连贯、表情是否有表演依据、服装与道具是否可用、状态变化是否有来源。
