# 双人战斗动作视频方法

## 输入门槛

需要场景 revision、双方角色 revision、武器或徒手设定、能力边界、起始站位和动作节拍。任何一项会改变动作可行性时先提问；不能用通用打斗词替代缺失的空间与身体条件。

## 段落切分

每个视频段落只承载模型时长内可清楚阅读的一组动作：建立站位、一次主动策略、一次反应与一个稳定退出状态。段落之间通过身体朝向、重心、武器位置、视线和环境破坏连续，不靠模糊的“接上段”描述。

## 提示结构

依次表达镜头、人物与空间、动作向量、接触结果、环境响应、退出画面和声音。多角色时分别命名左右、前后或景深位置，避免“双方同时做动作”的歧义。参考图只负责身份、服装、武器或场景，不把设计板分屏带进视频。

## 物理与表演

动作强度与人物体力、伤情和训练一致。接触后必须有重心、距离或表情变化。镜头运动服务动作可读性；高频摇晃、不断变焦和无理由慢动作会削弱空间理解。

## 执行边界

提交前运行时校验模型支持的视频场景、参考素材、时长、比例、分辨率和音频参数，并核对真实资产权限。重试绑定同一逻辑段落的新 attempt 和预算范围；未知超时先查询对账，不自动重复生成。

## 交付

输出分段表、每段进入/退出状态、结构化提示、引用目的和连续性检查。没有已绑定视频 Tool 或 Provider 能力时只交规划稿并标 `DEPENDENCY_BLOCKED`。
