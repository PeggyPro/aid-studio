# 参考视频重制方法

## 授权与范围

确认用户有权使用参考视频及替换素材，并说明重制目标：学习节奏、镜头功能、产品呈现或叙事结构。避免逐帧复制独特构图、角色形象、商标或音乐；需要保留的品牌资产由用户明确提供。

## 时间线分析

按镜头或功能段记录起止时间、景别、机位、运动、主体动作、转场、色彩、声音和叙事目的。短尾段也必须记录；若容量过小，可建议合并、后期裁切或调整范围，但不能静默删除。

## 替换映射

建立“参考功能—新素材—变化理由”表。替换人物时维护身份、造型与动作可行性；替换产品时维护比例、材质、标识和使用方式；替换场景时重新验证光线、动线与镜头运动。

## 原创重组

保留的是信息顺序、情绪曲线和镜头职责，具体动作、构图、场景细节和声音应适配新目标。遇到参考内容与新品牌价值冲突时，优先重设镜头功能，不强行照搬。

## 声音与配乐

分离对白、环境、拟音和音乐。视频生成段默认只规划画面相关声音，配乐作为独立时间线资产统一设计，避免每段生成不同音乐。参考音乐无授权时只分析节奏和情绪功能。

## 交付与依赖

输出分析时间线、替换映射、原创镜头表、素材清单、声音计划和版权风险提示。实际视频分析、剪辑、字幕、音频分离和合成均需已绑定工具；缺失时标明具体依赖，不声称成片完成。
