# 高动势汽车广告方法

## 四类锚

产品锚保存车身比例、颜色、材质、灯组、轮毂和标志；光线锚保存方向、色温与反射；场景锚保存道路、天气和地标；构图锚保存机位、景别和运动关系。每镜只引用实际需要且模型容量允许的锚。

## 感官结构

可用“识别—接近—启动—释放—余韵”组织短片：先让观众看清产品符号，再建立人与车或环境的关系，通过机械细节触发运动，在主体段展现性能与空间，最后回到品牌印象。各段比例按时长和卖点调整，不写成不可改变的固定幕表。

## 镜头与运动

交替使用英雄机位、贴地跟随、车身细节、驾驶视点和环境尺度。运动方向、道路位置、天气与车身状态保持。高速段也要给产品轮廓和标志足够可读时间；视觉故障或闪帧只在有创意理由时有限使用。

## 动态检查点

主 Agent 根据输入成熟度决定何时确认：产品身份不清、创意方向分叉、镜头表会扩大费用、第一批结果暴露身份漂移或配乐改变品牌语气时再询问。不是每个项目都必须经过同样数量的门，也不能追溯批准已经收费的动作。

## 执行与重试

独立镜头可在运行时并发上限内执行，有依赖的镜头串行。问题镜头局部重做，保留已通过产物。达到重试上限、价格变化或模型升级时暂停并重新报价；具体次数和并发由代码配置。

## 交付

输出锚表、感官结构、镜头表、声音分段、检查点建议和身份连续性清单。不得硬编码模型、分辨率、并发数、重试数或混音比例。
