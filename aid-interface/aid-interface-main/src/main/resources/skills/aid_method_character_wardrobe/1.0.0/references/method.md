# 人物装造提炼方法

## 输入与证据

接受剧本片段、人物小传、参考图或已有角色资产。每条结论标为：明确事实、图像观察、用户选择、可替换假设。图片模糊、遮挡或来源冲突时列出缺口，不凭印象锁死五官和服装。

## 结构化拆解

按身份与年龄段、体型比例、脸部识别点、发型结构、妆容、上装、下装、鞋履、配饰、材质与磨损、场景适配性整理。服装不仅写名称，还要说明轮廓、层次、开合方式、主要材料、颜色关系和剧情功能。

建立“不变量”和“可变项”：身份识别点、剧情指定伤痕和标志物通常不可变；造型版本、季节层次、妆面强度和状态磨损可以按场次派生。派生造型引用基础角色 revision，不覆盖原资产。

## 视觉转译

把文字事实转成模型可理解的外形描述时，避免夸张人体比例、固定肤色或无依据的审美模板。写实目标应关注真实材质、自然皮肤与发丝、合理关节和一致光源；插画或动画目标则明确线条、色块和材质语言。模型私有参数由 Provider 适配器处理。

## 多视图资产

建议先形成中性站姿的正、侧、背视图，再按需要增加脸部近景、表情或服装拆解。多视图是同一资产的设计板，不是视频中的分屏指令。背景、镜头距离、比例和光线保持一致，以便比较轮廓；生成前由代码核验参考图数量、比例和模型能力。

## 交付与自检

交付装造清单、不可变识别点、可变造型列表、未决问题和可编辑视觉提示。检查是否误把风格偏好当人物事实、是否丢失剧情指定细节、前后视图是否能解释服装结构、所有引用是否绑定真实资产 revision。生图、保存与接受结果只能通过运行时动作。
