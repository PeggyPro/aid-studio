# 叙事产品广告方法

## 产品读片

从用户资料和产品图中提取可见事实：形态、材质、颜色、部件、标志、操作方式、使用环境和真实限制。把营销主张与可验证事实分开，缺少证据的功能不写成确定承诺。

## 卖点转情绪

将卖点写成用户在什么情境下遇到什么阻力，产品如何改变行动或感受。避免直接朗读参数；参数可以通过动作结果、时间变化、空间变化或对比被看见。

## 创意候选

提出三种机制不同的方向，例如人物小故事、产品视角或场景隐喻。每个方向包含受众、情绪承诺、产品角色、核心动作、视觉系统、风险和交付范围。用户选择后才扩展完整脚本。

## 控制资产

建立产品多视图、关键使用动作、主要人物和场景基准。控制原画验证产品比例、手部接触和场景光线；不把氛围概念图直接当成可生产镜头。

## 镜头与声音

镜头按问题出现、尝试、产品介入、感受变化和品牌余韵组织，可根据创意重排。环境、拟音、对白、旁白和音乐分轨，品牌字版在后期保持可编辑。

## 审核

检查事实与推断、产品外观、Logo、动作可行性、卖点是否真正被看见、情绪是否过度承诺、素材授权和后期声明。任何生成与合成动作都受模型能力、报价和批准范围约束。
