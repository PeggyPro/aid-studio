# 分支拳击叙事方法

## 设计目标

让每回合因体力、伤势、战术暴露和人物关系而变化，避免重复交换动作。先确认回合范围、两名选手的目标与风格、教练关系、裁判尺度、场地和允许的结局。建议先用较短范围验证状态与分支，再扩展完整比赛。

## 状态模型

至少记录体能、局部伤势、节奏控制、距离偏好、心理压力、犯规风险、裁判警告和角落建议。状态变化必须由可见事件触发，并影响下一回合可用选择。状态值属于交互引擎事实；提示词只建议变化及依据。

## 回合结构

每回合包含：开局意图、对手适应、一次优势转换、代价、回合末判读和角落决策。动作以空间、重心、距离、护架和反应描述，避免罗列招式。镜头同时维护比赛轴线、选手左右关系和裁判位置。

## 选择与后果

选择要改变后续策略或资源，而不只是换一句对白。每个选项说明即时收益、潜在代价和可见反馈；隐藏后果可以延迟揭示，但必须来自既有状态。失败路线也应产生可继续叙事的结果，不用随机惩罚替代因果。

## 结局

胜负可以来自技术终止、点数、犯规、主动放弃或人物目标改变。结局条件由状态引擎判定，创作方法负责确保每条结局有前置迹象和情感兑现。不要在最后回合临时改规则。

## 交付

输出回合表、状态字典、选择图、镜头连续性说明、结局条件和测试案例。若缺少交互引擎、状态持久化、分支格式或发布工具，状态应为 `DEPENDENCY_BLOCKED`；不生成伪造的可运行文件，也不自动升级到更贵模型。
