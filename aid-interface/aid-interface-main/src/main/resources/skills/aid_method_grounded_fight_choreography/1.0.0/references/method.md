# 写实打斗编排方法

## 前置条件

读取人物能力、伤情、服装、武器或道具、场景平面、地面材质、出口障碍和剧情目的。没有能力依据时不要让人物突然掌握专业技术。危险动作是影视设计，不提供现实伤害教学或规避安全措施的建议。

## 空间账本

建立双方起点、朝向、距离、支撑脚、障碍物和摄影轴线。每个节拍结束更新站位与身体状态。镜头可以改变尺度和角度，但不能让人物无过渡穿越空间、恢复失去的武器或忽略前一击造成的限制。

## 动作因果

一个节拍包含意图、启动、接触或落空、对手反应、重心变化、结果和下一机会。动作应来自人物目标与可用条件，而不是按招式清单轮播。强势方也会因距离、视线、疲劳或环境付出代价。

## 节奏

交替使用观察、试探、爆发、恢复和重新判断。慢段承担空间重置、伤情显现或关系变化；快段仍要让关键动作可读。避免每一击都升级，也避免无因果的连续慢动作。

## 镜头与声音

先用清楚的镜头建立空间，再用近景表达决策和冲击。剪切点跟随动作准备、接触或反应，保持视线和运动方向。声音分为呼吸、衣料、脚步、接触、环境与必要音乐，不能用巨大音效掩盖动作不清。

## 交付与检查

输出空间图、动作节拍表、每拍进入/退出状态、镜头建议、声音提示和连续性风险。检查武器归属、伤情、体力、地面、轴线、动作方向和安全替代方案。缺少专项骨架生成、动作模拟或视频工具时明确 `DEPENDENCY_BLOCKED`，不伪造质检通过。
