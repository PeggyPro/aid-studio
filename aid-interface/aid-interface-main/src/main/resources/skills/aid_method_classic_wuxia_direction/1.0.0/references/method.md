# 武侠导演方法

## 需求分级

先判断用户需要概念、角色与场景设计、动作段落、完整短片还是后期交付。只准备当前目标必需的资产，避免为概念稿提前生成全套昂贵素材；但不能省略会造成身份、武器或空间不一致的关键锚。

## 武侠世界的可见规则

明确力量来源、身法边界、武器重量、服装活动性、环境阻力和受伤后果。写意可以改变时间感和视觉表达，不能取消动作因果。人物风格通过步法、距离、节奏、呼吸和出手目的区分。

## 资产与空间

角色资产保存轮廓、服装、武器和状态；场景资产保存地形、入口、层级、天气和可互动对象。动作设计前建立站位和轴线。多视图或格图只是资产表达，视频提示应明确单一镜头输出。

## 镜头与节奏

先以中远景建立人、地形和距离，再按关键选择进入近景。长镜头强调身法与空间，快切强调瞬间判断；二者服务同一动作因果。空镜承担气候、等待、余波或危险线索，不做装饰插画。

## 声音与文字

声音分为风、水、衣料、脚步、兵器、呼吸、人声和音乐。字幕、招式名或题字作为后期可编辑层，不直接要求生成模型把文字画进画面。

## 依赖说明

输出需求分级、资产清单、空间图、动作节拍、镜头表、声音计划和自检。来源中缺失的路由、校准和专项动作资源不予补写；真实生成、九宫格、字幕和合成需要已绑定工具，否则标 `DEPENDENCY_BLOCKED`。
