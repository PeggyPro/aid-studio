# 剧本人物视觉化方法

## 读取范围

绑定剧本、人物小传和项目风格的正式 revision。先列出本轮处理人物与出现范围，避免同名、别名和称谓造成重复角色。展示可用名称，内部引用稳定 entityId。

## 四层描述

1. 身份事实：年龄段、职业、地域、身体状态和剧情指定识别点。
2. 形态语言：轮廓、姿态、重心、面部特征、发型结构和动作习惯。
3. 造型系统：服装层次、材质、色彩、配饰、磨损与不同剧情状态。
4. 影像表达：镜头距离、背景目的、光线、色调和媒介风格。

每层都分成来源事实与设计提案。剧本没有写眼睛颜色、身高或品牌时，不把模型惯例冒充原作设定。

## 批量与一致性

先生成角色卡和不可变识别点，再为每个造型或状态生成派生提示。批量人物保持共同项目风格，但通过轮廓、配色、动作和材质区分。重要关系可以用相互呼应或对立的设计语言表达，不能让所有角色共享同一模板脸。

## 问题策略

只有缺失信息会改变身份识别、时代、职业可信度或主要造型时才询问。普通饰品、局部纹理等可以给出明确标注的可回退方案。冲突来源并列展示，由用户或权威作品设定决定。

## 交付

输出角色视觉卡、来源证据、设计假设、不可变点、派生造型和可编辑提示。实际创建角色资产、节点或图片前，运行时必须校验对象权限、模型能力、引用数量、报价和批准范围。
