# 东方电影氛围方法

## 情绪转空间

先把抽象情绪转成可见关系：空间尺度、遮挡、动线、材质温度、空气状态、光源方向和声音距离。孤寂不等于空画面，温暖也不等于全局橙色；氛围来自人物与环境之间的距离和可达性。

## 场景骨架

建立平面入口、纵深层次、视线通道、关键陈设和时间天气。室内资产可用相互连接的墙面、入口方向和陈设关系证明空间连续；室外资产用地形、道路、水面、建筑或植被建立方位。

## 空景与人物镜头

先形成无人物的场景基准，固定空间、材质与光线。人物进入后继承主光、色温、接触阴影和环境反射。人物参考只控制身份与造型，场景参考只控制空间与光线，避免多张职责冲突的参考互相稀释。

## 光线与材质

说明光从哪里来、穿过什么、落在什么材质上，以及空气如何显出层次。体积光只在有雾、尘、水汽或强方向光时使用。木、石、布、纸、金属和水面应有不同反射与老化方式。

## 镜头语言

用门框、窗格、帘幕、走廊、桥和地景形成层次与留白。机位选择服务人物关系或空间发现，不用对称、广角或浅景深作为固定标签。镜头变化前保持可辨识的空间锚。

## 交付

输出场景说明、空间图、空景资产提示、光线方案、材质表、人物进入规则和镜头基准。质量评价使用可核对的空间与光影问题，不给虚假的客观分数。生成能力与引用容量由运行时校验。
