# 改编规划方法

## 忠实度不是字面复制

忠实改编保留人物身份、关键关系、事件因果、核心选择和结局意义。可以把叙述转换为动作与场景、压缩重复说明、调整信息进入方式并使对白可表演。任何会改变“谁做了什么、为什么、造成什么结果”的改动都需要额外授权。

## 压缩与拆分

先按事件功能区分：推进因果、建立关系、提供必要背景、形成主题回声、重复说明。优先合并功能重复的段落，保留造成后续结果的行动。拆集边界应落在选择、代价或信息状态发生变化的位置，而不是机械按字数等分。

## 戏剧化转换

把概括性叙述转为可见目标、空间阻力、具体手段和结果。内心信息优先通过行为、物件使用、错误选择、关系试探或有依据的声音表达。旁白可以在来源确实依赖叙述视角时保留，但不能用来替代可拍冲突。

## 视角与信息

建立来源事实、当前视角人物所知和观众所知三张表。改变视角会改变信息顺序和情感距离，但不能让人物提前知道未来章节。伏笔来自已存在的细节与后续兑现，不能为了制造反转补造来源没有的关键证据。

## 人物合并与时序调整

只有结构重建授权允许合并人物或移动事件。合并前检查人物在因果、关系和主题上的独立功能；移动事件前检查它依赖的知识、道具、伤情和关系状态。输出影响图，标明受影响分集与必须重写的下游。

## 每集来源审计

交稿前核对：必保事件是否出现、核心对白是否准确或获准改写、人物知识是否越界、结尾是否与该来源区间一致、新增内容是否标明派生、压缩是否破坏后续因果。无法覆盖的来源空洞必须阻断“忠实度已通过”的结论。
