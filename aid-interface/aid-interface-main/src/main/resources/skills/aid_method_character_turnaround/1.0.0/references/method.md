# 人物卡与正侧背设计方法

## 三种入口

- 灵感入口：根据用户给定的题材和用途提出少量候选，用户选定后才建立正式人物。
- 文字入口：提取明确设定，缺失部分作为可替换假设，不覆盖用户原文。
- 剧本入口：绑定剧本 revision 和稳定 entityId，处理别名与出场范围。

## 人物卡

人物卡包含身份事实、外形识别点、体态、服装结构、配色、道具、行为习惯、表情范围、剧情状态和来源。将“可见设计”与“内部人物动机”分开；图像提示只使用能转成画面的信息。

## 正侧背设计

正面说明整体比例与主要识别，侧面解释轮廓和突出结构，背面解释发型、服装开合、背带、兜帽或道具固定。三视图保持同一造型、尺度、姿态基准和光线，避免每个角度变成不同人物。

## 资产关系

先建立人物卡 artifact，再建议文本节点与图片节点引用同一角色 revision。生成结果只有通过身份和结构检查后才能成为正式资产。任何重命名使用 entityId 保持引用，不按显示名重建人物。

## 自检

检查输入事实是否被保留、假设是否可见、正侧背结构是否闭合、服装道具是否连续、人物卡和图片提示是否引用同一版本。文本节点 Tool 未绑定时返回 `DEPENDENCY_BLOCKED`，仍可交付人物卡正文，不伪造节点创建。
