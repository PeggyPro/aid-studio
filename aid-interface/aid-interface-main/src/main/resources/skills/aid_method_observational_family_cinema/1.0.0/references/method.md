# 生活观察电影方法

## 戏剧从日常动作发生

先找关系里的未说出口之事，再选择能让它浮现的日常任务：吃饭、收拾、接送、等待、修理、告别。动作与物件承载关系变化，避免人物用完整台词解释主题。

## 空间与距离

家庭空间记录座位、门窗、走廊、公共区与私人区。人物靠近、回避、隔门交谈或共享物件都体现关系。镜头保持足够观察时间，让微小行为具有含义，不以持续特写强迫情绪。

## 表演

写具体动作、迟疑、视线、呼吸和被打断的语言。沉默必须有正在进行的任务或关系压力。角色可以表达不准确，但行为与后续结果要让观众理解差异。

## 光线与色彩

优先使用环境中可信的窗光、室内灯、天气和时间变化。色彩来自墙面、衣物、食物和季节，不用统一滤镜覆盖材质。人物进入场景时继承光源和接触阴影。

## 声音、字幕与音乐

环境声、家务声、远处交通和房间混响建立生活空间。音乐克制使用，给表演留呼吸。字幕和混音是后期资产，增益调整要检查峰值和对白可懂度，不直接照搬固定分贝。

## 交付

输出关系压力、日常任务、空间图、镜头观察点、表演动作、环境声与后期计划。评审关注人物是否通过行动发生变化、场景是否有空间真实感和情绪是否被过度解释，不用艺术家相似度打分。
