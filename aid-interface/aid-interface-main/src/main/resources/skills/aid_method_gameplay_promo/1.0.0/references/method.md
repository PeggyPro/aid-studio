# 游戏体验宣传片方法

## 先确认真实性层级

区分实机录制、预演动画、概念影片和混合宣传。每个镜头标注来源，不能把概念动画包装成真实玩法。用户提供的原画、模型、界面和商标需要授权与版本指针。

## 体验承诺

用一句话说明玩家做什么、为什么有趣、反馈是什么。镜头结构围绕“规则被看懂—能力被尝试—风险升级—掌握产生回报”展开，而不只是角色摆姿和环境漫游。

## 资产层级

世界基准定义尺度、材质和移动规则；角色资产定义轮廓、装备和技能可视语言；敌人与道具定义读秒和反馈；界面资产解释信息层级。二维原画、多视图、三维模型与最终镜头分别管理，不能用一张设计板冒充所有阶段完成。

## 镜头与界面

建立玩家视角、角色视角、演出镜头和城市漫游等镜头类型。界面只显示对当前动作有用的信息，保持可编辑安全区和清晰层级。没有真实游戏状态时，界面要标为演示，不伪造可交互结果。

## 声音与节奏

动作反馈、环境、技能、人声与音乐分层。节奏跟随玩家理解：新规则需要可读时间，熟悉后的组合可以加速。音画峰值服务关键掌握时刻，不持续轰炸。

## 依赖与交付

输出真实性声明、体验承诺、资产表、镜头表、界面事件、声音时间线和素材来源。三维、界面合成、视频生成和剪辑能力未绑定时标明依赖；不使用来源中的私有生成器名或编辑器名。
