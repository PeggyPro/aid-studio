# 哥特权力短剧方法

## 情感核心

力量展示必须服务人物的孤独、代价或身份冲突。建立公开身份、隐藏能力、具体恐惧和控制习惯；反转不是不断加入更强敌人，而是让一次力量使用改变关系或暴露代价。

## 视觉系统

使用冷暗基底、方向清楚的硬光、湿润石材、旧金属、皮革和少量暖色信号建立世界。暖色只在情感、危险或人性接触时出现。写实、立体动画和绘制动画是不同方向，用户确认后不无理由混用。

## 分集与段落

集数、单集长度和段落容量取自用户目标与模型能力。每集包含压迫状态、人物隐忍或试探、一次具体选择、力量或身份变化、短暂余波和新的压力。纯动作与沉默同样占用时长，不能只按对白字数决定段数。

## 角色与场景资产

角色资产记录轮廓、服装材质、伤情和状态；场景资产记录光源方向、地面、入口、空间轴线和可互动材质。资产多视图允许正面基准，视频镜头角度另行选择，避免“需要正视图又全局禁止正面”的冲突。

## 视频与声音

每段明确动作驱动、强弱变化、镜头、光线、退出状态和环境声。画面文字作为后期层。配乐统一设计，现场声音突出脚步、衣料、金属、雨水和房间混响，不把每段音乐写进生成提示。

## 自检

检查反转是否有因果、力量是否有代价、硬光方向与轴线是否连续、资产状态是否正确、对白是否推动行动、暴力是否符合项目分级。不得使用艺术家姓名、固定导演指令、固定模型或无依据的集数与字数。
