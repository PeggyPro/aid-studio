# 原创流程方法

## 1. 方向检查点

把用户已有设定整理为“必须保留、允许探索、尚未决定”三栏。若核心题材、主角、受众或目标体量仍有多种会显著改变成品的解释，提出三到四个差异清楚的方向，并把用户已给的集数、时长和风格放入默认答案。这个阶段只形成方向提案，不把候选当正式大纲。

方向说明应回答：观众为什么继续看、主角要得到什么、阻力如何迫使选择、失败会失去什么、第一阶段能兑现什么。方向之间要改变冲突机制或情感承诺，不能只换标题和表面元素。

## 2. 骨架检查点

方向确认后形成以下互相引用的产物：

- 总体设计：题材、观看承诺、核心矛盾、结局方向、目标集数与时长。
- 故事推进图：起始失衡、升级节点、不可逆转向、最低点、终局兑现。
- 人物资产：稳定身份、当前欲望、误判、手段、关系、可见习惯和弧线触发条件。
- 场景资产：空间功能、可拍特征、进入条件、离开后的状态变化。
- 道具资产：所有权、使用规则、信息含义和连续性风险。
- 分集计划：每集承接状态、当集问题、主要行动、转向、结果、未结代价和下一集压力。

总集数较长时可分为若干阶段，但阶段只用于管理持续升级，不机械平均集数。每一阶段应有独立目标、主导阻力、人物变化和退出状态。

骨架交付时列出关键假设与风险，请用户确认方向和体量。用户直接修改产物时，以最新正式 revision 为准，不要求重复回答已体现在文件中的决定。

## 3. 首集样片检查点

首集先写一份可执行单集计划：开场状态、当集欲望、阻力、信息释放、关键选择、局部兑现、结尾状态。再写规范正文并请求独立审核。审核只修有证据的客观问题；审美分叉返回用户选择。

首集的价值是校准整部作品的声音、信息密度和可拍性。用户确认前，不把首集风格自动推广到全部分集。确认后，运行时才可根据已批准范围逐集继续。

## 4. 后续分集循环

每集开始只装配必要上下文：全剧骨架、当前阶段、人物和资产的最新状态、前集正式正文的退出状态、当集计划。完成正文后执行审核、一次有界修订和正式提交。下一集只读取已提交版本，不读取未采纳草稿。

用户中途改动骨架时，先生成影响清单：受影响的分集、人物弧线、伏笔、道具状态和既有正文。小范围修改可在同一结构版本内修订；改变集数、结局或核心因果时建立新计划 revision，并由用户决定迁移范围。

## 5. 停止与恢复

本方法不自行维护“正在第几集”。暂停、取消问题、停止生成或恢复时，读取运行时的权威 checkpoint、产物 revision 和在途任务。未知状态先对账，不重写同一集，也不把停止请求解释为自动退款。
