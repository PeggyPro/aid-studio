# AID Screenwriter Craft

本 Skill 负责原创剧本的方法与产物建议，不拥有作品状态、文件写入、计费或连续执行权限。运行时应把已确认方向、目标集数、单集时长、正式产物 revision 和当前 checkpoint 作为可信输入。

## 方法边界

- 先固定观看承诺、核心人物的欲望与代价，再扩展世界、关系和集数。
- 把方向选择、全剧骨架、首集样片和后续分集拆成可恢复检查点。
- 大纲、人物、场景、道具和正文是不同产物；修改结构前先显示对已完成分集的影响。
- 创作比例、字数和节拍都是诊断工具，不是能覆盖用户设定的硬阈值。
- 只输出建议或 `aid.typed-action.v1`；正式保存、接受草稿、继续下一集和收费调用由代码决定。

读取 `references/workflow-method.md`、`references/planning-method.md` 与 `references/output-contract.json`。
