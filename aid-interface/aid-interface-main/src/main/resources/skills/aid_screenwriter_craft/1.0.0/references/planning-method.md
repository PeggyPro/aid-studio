# 原创规划方法

## 命题与观看承诺

把主题写成一个会迫使人物行动的矛盾，而不是抽象口号。先问：主角相信什么，现实如何反驳，他为了证明自己会采取什么行动，这个行动给谁造成代价。观看承诺要能转化为反复变化的情境，例如“每次解决眼前问题都会扩大更难承认的关系债务”。

## 人物引擎

每个主要人物至少有五个维度：公开目标、隐蔽需要、惯用手段、不可承受的损失、在压力下暴露的矛盾。配角不靠标签区分，而靠他们对同一事件采取不同手段。人物变化必须落在选择、关系、身体行动或资源得失上。

关系弧线用“谁需要谁、谁控制什么、双方误解什么、哪次行动改变权力”描述。不要用固定人数、固定反派或固定爱情线填表；只有对当前故事有作用的关系才进入骨架。

## 因果与升级

场景之间优先使用“因为上一行动造成结果，所以人物必须采取下一行动”。若场景可以任意互换顺序，检查它是否缺少状态变化。升级可以来自选择空间收窄、代价外溢、秘密被错误的人知道、旧手段失效或目标本身改变，不依赖不断加入更大的外部事件。

转向需要同时改变至少一项：人物目标、可用手段、关系权力、观众理解或时间压力。反转应由已经存在的事实和行动触发，不靠临时补造身份、证据或规则。

## 信息与情绪

分别记录世界事实、人物认知和观众已知。悬念来自三者的差异，不能通过让人物无理由隐瞒解决。信息释放要改变当前行动，而不是只补背景。

情绪曲线用“期待—摩擦—失衡—选择—余波”检查局部变化。连续高强度会让差异消失；安静段也要承载观察、犹豫、关系试探或代价累积。

## 单集与场景

单集计划回答：从什么未稳定状态开始，谁想改变它，阻力怎样具体阻止，哪次选择形成不可逆结果，结尾留下什么新状态。钩子是结果带来的新问题，不必固定为秘密揭晓或危险闯入。

每场正文只写观众可见、可听和可表演的内容。动作说明人物怎样改变空间或对象；对白体现当下策略，允许停顿、回避、误解和次要目标。删除一句对白后若人物行动和关系完全不变，检查它是否只是解释。

## 容量与可拍性

目标分钟数用于估算，不把固定字数当作所有语言、表演和动作的统一换算。分别统计对白、动作、场面调度和沉默所占时间，并给出估算区间。超出容量时先调整事件密度、合并重复功能或重新分集，不能加速语速、删除必要因果或把未拍内容藏进旁白。

## 自检

交稿前检查：承诺是否兑现、因果是否连续、人物知识是否越界、场景是否产生变化、动作是否可表演、对白是否有策略、资产是否保持连续、目标时长是否合理。无法从文本证明的判断标为审美建议，不伪装成硬错误。
