# 边疆决斗电影方法

## 空间先行

在特写之前建立双方站位、距离、朝向、地形、掩体、摄影轴线和运动方向。后续眼神、手部和道具近景只改变尺度，不改变已经建立的空间。需要越轴时用可见摄影机移动或中性镜头重新建立。

## 人物与材质

角色轮廓、服装、帽饰、鞋、随身物与风化程度形成识别系统。道具归属和位置跨镜保持。场景用尘土、木、旧金属、皮革、日晒和天气构成触感，不靠艺术家标签生成气氛。

## 节奏

对峙阶段通过距离、视线、呼吸、脚步、手与道具建立延迟；爆发阶段使用极短且方向清楚的动作；余波重新拉长，让结果、环境和人物选择可见。快剪源自后期裁切，不强迫生成模型产出不可读的极短片段。

## 镜头

远景和越肩镜头建立轴线，近景分开拍摄人物的眼、手和反应，避免模糊的复数动作。动作向量同时说明人物身体方向、对手位置和屏幕方向。资产设计板必须标注为参考表，视频输出保持单一画面。

## 声音

环境、脚步与装备、关键冲击、人声和音乐分轨。用户已有合法音轨优先复用。高潮前可以减少音乐让环境与动作突出；具体电平由混音工具测量，提示词不硬编码固定增益。

## 交付

输出空间锁、角色与场景资产、对峙/爆发/余波镜头表、动作方向、声音时间线和连续性检查。实际裁切、混音、生成与合成需要受控工具；缺少时只交规划稿。
