# 成年女性角色审美设计方法

## 设定基础

确认角色为成年人物，并读取职业、时代、生活方式、剧情功能、气候和行动需求。人物魅力从具体性格与生活痕迹建立，不以统一身材、暴露程度或幼态特征作为默认。

## 方向候选

为用户提供少量差异清晰的方向，例如克制职业感、松弛生活感、舞台化表现或功能性行动造型。每个方向说明轮廓、主色、材质、妆发、姿态和适用剧情。大量造型只能作为检索库，用户选定后才创建对应资产。

## 服装系统

区分基础衣橱、场景造型、特殊事件造型和状态变化。每套记录上装、下装或连体结构、外层、鞋、配饰、材质与活动限制。服装应能从正侧背解释，且符合角色携带道具和动作需要。

## 表情与姿态

表情由眼周、眉、嘴、下颌、头颈和手势共同构成。姿态体现角色在空间中的关系，避免每个方案都使用同一站姿。设计表可以含中性、工作、亲密、戒备、疲惫等对剧情有用的状态。

## 可控修改

用户要求换服装时保护脸、发型和身体事实；要求换发型时保护服装与身份。涉及多个变量的重设计先列差异。文字排版、海报字版与无字角色图分开交付，未绑定排版工具时不声称完成字版。

## 交付检查

交付身份基准、方向候选、选定造型、服装拆解、多视图与表情建议、变体继承关系。检查成年设定、职业可信度、活动可行性、前后结构、配饰连续性和用户变量保护。
