# 照片级保真重建方法

## 保真基线

先记录原图尺寸、比例、主体、构图、文字、边缘、透视、遮挡和不可辨区域。将“必须保留”“可修复”“需要用户决定”分开。原图含人物时，身份特征和姿态属于高风险内容，不能用通用美化模板覆盖。

## 结构辅助

可使用轮廓、线稿、深度或分区蒙版作为结构中间产物。它们用于约束几何，不是新的创作目标。多个中间分析可并行，但最终重建必须绑定相同源 revision、裁切范围和比例。

## 重建层次

先修复大形与透视，再处理材质和局部细节，最后调整色彩与噪点。不可辨区域以低风险、与周边一致的方式补全并标注推断；对脸、文字、标识和关键道具不做无依据重绘。

## 分辨率策略

输出尺寸依据原始比例、用户用途和实际模型能力选择，不强制拉伸到固定横屏规格。放大不能创造可信事实；如果源图信息量不足，说明可恢复的实际上限。多次放大应从已接受的中间版本继续，避免反复压缩。

## 对比验收

比较主体位置、轮廓、透视、身份、色块、文字和关键细节。质感更锐利不等于更保真。若差异影响语义，提供原图、候选图和差异说明，请用户决定；不以主观评分冒充测量。

## 依赖

线稿、深度、蒙版、图像生成和放大均需精确 Tool 绑定。缺少任何关键环节时交付修复方案和可执行前提，标明 `DEPENDENCY_BLOCKED`，不声称已完成高分辨率重建。
