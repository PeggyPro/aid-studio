# 几何与色彩叙事方法

## 先决定秩序的意义

对称、正面机位和中心构图应表达控制、仪式、童话距离或人物被规则困住，而不是每镜的装饰。允许在关键时刻破坏秩序，以偏位、遮挡或运动显示关系变化。

## 色彩系统

为人物、地点和叙事阶段定义主色、辅助色和警示色。颜色变化要跟随状态，不因单镜审美随意漂移。服装、墙面、道具和文字层共同构成色彩，不靠后期滤镜挽救冲突资产。

## 空间与机位

建立轴线、中心点、层级框架和人物站位。正面镜头强调图形关系，侧向或俯视镜头用于揭示隐藏结构。运镜以平移、垂直、推拉等可读路径为主，变化服务新的信息。

## 人物与道具

人物表演可以克制，但要通过精确站位、眼神、手势和道具操作显示意图。重要道具的位置与颜色具有连续性，不能为构图方便随意换边。

## 字幕与品牌层

标题、章节卡、品牌字和字幕在后期以可编辑安全区管理，不要求生成模型绘制准确文字。字体、字号、对齐、留白和进入退出动画形成独立规范。

## 交付

输出叙事秩序、色彩脚本、构图规则、允许破格的节点、角色与场景资产、镜头表和图形层规格。不得使用艺术家姓名、私有风格参数或固定 seed；工具未绑定时不声称合成完成。
