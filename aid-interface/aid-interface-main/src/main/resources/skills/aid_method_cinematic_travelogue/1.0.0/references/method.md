# 电影感旅拍方法

## 目标与视角

根据已有信息确定地点、人物、用途、平台和情感主题。主 Agent 只有在缺失项会改变叙事、费用或素材范围时才动态提问；比例、时长、模型和旁白不做固定问卷，也不擅自选择收费模型。

## 观察素材

把地理事实、用户经历、现场观察和创作想象分开。真实地点资料要记录来源与时间；用户未提供现场参考时，可以先提出取景清单或场景概念，不把概念图冒充真实地点。

## 故事线

从“来到这里之前—现场发现—关系或理解变化—离开时带走什么”组织旅程。旁白是观察与内心的补充，不重复画面。没有旁白也可以用动作、环境声、路线和物件形成叙事。

## 人物与场景资产

人物身份、服装和旅行状态按 revision 管理。场景按地点、时间、天气、方向和可用机位建立。人物进入真实场景时继承光线、噪点和接触阴影；没有合格身份或场景参考时先解决资产，不直接生成长视频。

## 时间线与声音

把旅程拆为功能明确的素材单元：定场、移动、观察、互动、细节、停留和离开。每段记录进入/退出状态。视频段保留环境与动作声音，配乐和旁白作为独立轨道统一选择与混合。

## 质检与交付

质检关注地点真实性、人物连续、路线逻辑、旁白与画面互补、声音层次和素材授权。重试次数、模型升级和预算由运行时决定。输出故事线、取景与资产表、镜头时间线、旁白草稿、声音计划、封面文案建议和缺失依赖；不伪造未提供的六个子 Skill。
