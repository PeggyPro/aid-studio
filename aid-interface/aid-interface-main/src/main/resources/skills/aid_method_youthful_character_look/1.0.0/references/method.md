# 清新生活感角色方法

## 角色核心

先从用户事实中确定成年身份、年龄区间、面部识别点、气质、发型和常用服装。清新感来自放松姿态、克制表情、自然配色和生活化环境，不靠幼态化、过度磨皮或统一脸型。涉及年龄模糊时先确认成年设定。

## 身份与造型版本

建立一个基础身份版本，并把发型、服装和妆面作为可切换造型。每个造型记录适用场景、不可变身份特征和允许变化的局部。更换造型时只改变被授权的变量；脸部、体型或标志物变化要产生新的角色版本。

## 资产顺序

建议按脸部基准、全身立绘、多视图、表情组的顺序规划。表情用眼周、嘴角、眉形、头颈和肩部的联动描述，避免只写抽象情绪。多视图保持相同镜头距离、服装和光线，表情资产保持同一身份与发型。

## 光影与场景融合

资产图使用中性、均匀、可比较的光线；场景图继承现场主光方向、色温、阴影和噪点。肤色清洁度与曝光分开处理：修复颜色偏差不能靠额外补光。人物与环境要有一致景深、边缘、接触阴影和颗粒，避免抠图感。

## 参考选择

参考图按职责分组：身份、姿态比例、服装、场景光影。不要堆叠互相冲突的同职责参考。最终引用数量、格式与分辨率必须由当前模型能力校验；超限时请求用户选主参考或拆分任务，不静默丢弃。

## 自检

检查成年设定、身份特征、造型版本、表情自然度、光源一致性、配饰连续性和场景接触。无法完成身份锁或后期合成时，交付可编辑设计稿并明确工具缺口，不声称成品完成。
