# 当代东方产品广告方法

## 产品事实

先提取产品比例、材质、颜色、结构、标志、开合与使用方式。产品多视图是身份锚，不能为了审美改变 Logo、接口、纹理或功能。不可辨信息标为待补资料。

## 创意方向

把东方语言落到空间秩序、材质、留白、节气、手工动作或现代生活仪式，不直接堆叠传统符号。提出少量方向并说明卖点、情绪、人物是否必要、场景与主光。

## 资产分支

纯产品方案强调轮廓、材质和使用细节；有人物方案额外建立人物身份、手部动作、服装与产品尺度；场景方案先生成无人物空间基准。所有资产绑定各自 revision 与引用目的。

## 镜头设计

按“发现—接触—理解—使用—余韵”或其他符合卖点的过程组织，不强制固定秒数模板。每镜说明产品状态、动作、机位、光线、声音和退出状态。短片容量由实际模型与目标时长决定。

## 字幕与声音

画面生成和文字排版分离。字幕、品牌字版与合法声明在后期时间线管理，保留可编辑文本。环境、拟音、旁白和配乐各自说明职责；配乐不在每个视频段重复生成。

## 检查与依赖

核对产品外观、标志、色差、手部接触、场景连续、字幕可读和音画节奏。帧提取、局部编辑、字幕和合成工具未绑定时交付镜头与后期规格，标明 `DEPENDENCY_BLOCKED`，不声称母版完成。
