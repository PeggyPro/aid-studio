# 情感奇幻短剧方法

## 情感引擎

先明确核心关系中的需要、误判、权力差和不能直说的代价。奇幻设定必须作用于选择和关系，而不是只提供服装与特效。每次能力使用都应有规则、限制或后果。

## 风格方向

提供少量视觉方向，例如真实质感、绘制动画或立体幻想，并说明角色资产、场景、动作和后期的差异。用户确认一个方向后保持统一；混合媒介需要明确转换节点。

## 分集结构

目标集数、单集时长和文字容量来自用户与运行时配置，不采用固定默认强行覆盖。每集含关系目标、外部阻力、一次认知变化、具体代价和结尾压力；纯动作段也计入时长，不能只按对白分段。

## 资产连续

人物身份、服装、发饰、能力表现和伤情分版本记录。正侧背设计允许正面资产基准；视频镜头是否避免正视属于镜头策略，两者不能写成互相冲突的全局禁令。

## 视频与声音

按实际模型容量切分连续段落，每段记录进入和退出状态、对白、动作、光线、镜头与环境声。配乐作为成片统一音轨规划；只有剧情中可见的现场音乐才进入具体段落。

## 交付

输出关系图、世界规则、风格方向、分集计划、资产版本、视频段落与声音方案。任何生成或连续执行都须重新校验预算、模型能力和批准范围。
